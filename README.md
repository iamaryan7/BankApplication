# 🏦 Bank Management System (Java Console Application)

A simple Bank Management System developed in Java using Object-Oriented Programming (OOP) concepts. This application allows users to create accounts, login securely, deposit money, withdraw funds, transfer money, check balances, and view transaction history.

---

## 🚀 Features

### 👤 Account Management
- Create New Account
- Secure Login System
- Logout Functionality

### 💰 Banking Operations
- Deposit Money
- Withdraw Money
- Transfer Money Between Accounts
- Check Account Balance
- View Transaction History

### 🔒 Security
- Password Authentication
- Account Validation
- Transfer Validation

---

## 🛠 Technologies Used

- Java
- OOP (Object-Oriented Programming)
- ArrayList
- HashMap
- Scanner Class
- Collections Framework

---

## 📂 Project Structure

```
BankApplication.java
│
├── Account Class
│   ├── Account Number
│   ├── Account Holder Name
│   ├── Password
│   ├── Balance
│   └── Transaction History
│
└── BankApplication Class
    ├── Create Account
    ├── Login
    ├── Deposit
    ├── Withdraw
    ├── Transfer
    ├── Check Balance
    ├── Transaction History
    └── Logout
```

### Compile


### Run

